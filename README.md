## Library App

### Description
This is a simple library management system that allows users to create, read, update, and delete data related to books, authors, categories, and publishers. 
The data is stored in a PostgreSQL database. The API is built using Java Spring Boot and tested using Postman. The UI is built using React and Material-UI.

### Using Technologies
- Java Spring Boot
- PostgreSQL
- React
- Material-UI

### Using for Deployment
- Netlify
- Render
